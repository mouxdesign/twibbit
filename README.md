# Twibbit

An open-source UX agent for bitcoin builders, built in public. You hand it to the AI agent you already use, and it carries a UX designer's judgment about how bitcoin apps should look and behave.

**Website and waitlist:** [twibbit.xyz](https://twibbit.xyz) · **Research report on the site:** [twibbit.xyz/research.html](https://twibbit.xyz/research.html)

## The research behind it

*We asked 10 bitcoin builders how they really build.* This is the Bitcoin Design Guide UXR Research Report, a transparent overview of every interview, with no assumptions and just real stories. Research by Mogashni, for the Bitcoin Design Community, supported by Spiral.

**What we found**

- **10 of 10** use AI to help write code.
- **6 of 10** use portable skill or instruction files.
- **6 of 10** make UX decisions without a UX specialist.
- **7 of 10** had AI output that was made up, wrong or misaligned.
- **9 of 10** asked for a skill or an agent their AI can connect to.

## What is in this repo

- `report/` is the research report, one file per chapter plus the [full report](report/full-report.md).
- `skills/` is where the Twibbit agent and its skill files live. Anyone can propose a new skill or an improvement to an existing one.
