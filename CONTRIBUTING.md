# Contributing to Twibbit

Twibbit is an open-source UX agent for bitcoin builders, built in public. Contributions are welcome, from a one-word fix to a whole new skill.

## Ways to contribute

- **Improve a skill.** Open a pull request on a file in `skills/`.
- **Propose a new skill.** Open an issue describing what it would check and why builders need it. Use `skills/_template/SKILL.md` as a starting point.
- **Report a wrong or missing recommendation.** Open an issue. Say what the agent suggested, what is wrong, and what it should say instead.
- **Correct the report.** The `report/` folder is a record of real interviews, so only corrections to errors are accepted there.

## Guidelines for skills

- **Say where a recommendation comes from.** Builders told us they want to know the source. Link a Bitcoin Design Guide page, a named wallet or another reference.
- **Do not make things up.** If a skill is not sure, it should say so.
- **Keep it plain.** Write for builders who are not designers.

## How changes are reviewed

Every change goes through a pull request. A maintainer reviews it before it is merged. Small fixes are merged quickly. Bigger changes may need discussion first, so open an issue.
